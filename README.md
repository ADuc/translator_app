# 🌐 AI Translator Pro - Offline

Ứng dụng dịch thuật và Text-to-Speech chạy hoàn toàn offline, bảo mật tuyệt đối.

## ✨ Tính năng

- 🔄 **Dịch đa ngôn ngữ** với AI local (Ollama)
- 🎯 **Dịch đồng thời** sang nhiều ngôn ngữ
- 🔊 **Text-to-Speech** với Qwen3-TTS
- 💾 **Lưu lịch sử** và xuất kết quả
- 🔒 **Offline 100%** - không gửi dữ liệu ra ngoài
- 🚀 **Giao diện đẹp** với Streamlit

## 📋 Yêu cầu hệ thống

- **RAM**: Tối thiểu 8GB (16GB khuyến nghị)
- **Storage**: 5GB trống (cho models)
- **GPU**: Khuyến khích có GPU (không bắt buộc)
- **OS**: Windows, macOS, Linux
